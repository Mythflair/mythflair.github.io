# 图片存储规范

网站图片统一存放在 `static/images/`，公开地址为 `/images/`。

- `static/images/<文章 slug>/`：一篇文章一个目录，与该文章实际网址的最后一段一致。没有显式 slug 时，以 Hugo 实际生成的网址为准。英、日译文共用中文原文的目录。
- `static/images/site/`：网站共用图片，包括 Logo、头像、首页图片、默认分享图及关于页、数字名片共用图片。
- `static/images/shared/`：多篇不同文章共用的图片，只保留一份。
- `static/images/` 根目录：尚未使用或暂时无法归属的文件，保留原文件名，暂不删除。

遗址、私人记录等独立内容页也按各自网址分目录。文章改标题时不需要改图片目录。新增图片尽量采用含义明确的文件名；本次整理保留历史文件名、格式及文件内容。

修改位置时，应同时更新正文、各语种封面、页面元数据、站点配置、模板、样式及 Hugo Pipes 中的资源路径。不要手工修改 `public/` 和 `resources/` 中的生成文件。

核对本次图片完整性（第二个位置参数仅用于保持命令接口，verify 模式不读取文章清单）：

```powershell

```

以后新增或替换图片后，这份历史清单自然不再与全量目录一致；应按新的变更范围核对。
