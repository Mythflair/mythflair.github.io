# 紫塞内容栏目与归类清单

主栏目使用 Hugo `categories`，普通文章只选一个：承德、生活、技术。`tags` 保留可交叉的细分主题。文章正文、发布日期、slug 和既有网址保持不变。

- **承德**：以承德本地地点、文化、美食、城市商业和共同记忆为主体的信息记录。
- **生活**：个人随笔、家庭、旅行、阅读、健康、职业回忆，以及非技术性的商业与管理观察；发生地点可以在承德或外地。
- **技术**：IT、通信、软硬件、AI、数据分析、系统设计和零售数字化实践，包括以这些问题为核心的技术管理思考。
- **遗址**：继续使用 `/legacy/` 固定目录及现有 `legacy: true` 归档，不参与三个普通栏目归类。

三种语言的导航“关于”及首页“关于紫塞”的了解更多链接均指向该语言的 `/posts/zisai.com/` 网站历史页；“关于沈楠”继续指向该语言的 `/about/` 个人简介。英文和日文导航同步三个主栏目及遗址入口。

旧分类的主题信息并入 tags，既有 tags 保留。例外：《终会等到为你而行的那辆公交汽车》的旧分类“网络技术”明显与正文无关，已更正为“生活”，不将错误分类转成标签。

边界示例：《力所能及》与等公交的感悟归“生活”；山庄大象滑梯的共同城市记忆归“承德”；IT 职业生涯回忆归“生活”；BBB、网络故障排查和 AI 零售系统实践归“技术”。普通商业、管理观察归“生活”，本地门店与街区介绍归“承德”。

本次整理 155 份文章文件，含译文和草稿。按当前构建配置，中文已发布栏目计数为：承德 7 篇、生活 79 篇、技术 62 篇。新文章使用 `archetypes/default.md` 创建，发布前应核对主栏目。

## 首页旅行标签入口

首页“分类浏览”同时展示三个主栏目、“旅行”“紫塞”“沈楠”主题标签，以及“遗址”“文章”目录入口；旅行链接到 `/tags/旅行/`，计数来自该标签下已发布的文章。标签可多选，增加“旅行”不改变文章的主栏目或其他标签。

旅行主题涵盖游记、城市漫游、旅途见闻和出行实用内容。除原有的卢塞恩、成都、冰岛、行李箱和航空经历等文章外，补充青岛、鄂尔多斯、日本街头乐队与航空电池文章。留学、职业回忆等仅偶然提及出行的内容不自动加入。
